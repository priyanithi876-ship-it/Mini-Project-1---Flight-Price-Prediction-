# Flight Price Prediction

## Project Overview

This project predicts flight ticket prices using machine learning. The trained model is saved as `model.joblib` and is used by a Flask web application to make predictions.

## Project Files

- `Flight Price Prediction.ipynb` - Jupyter Notebook for data analysis and model development
- `train_model.py` - Script used to train the machine-learning model
- `app.py` - Flask web application
- `model.joblib` - Trained machine-learning model
- `flightprice.csv` - Dataset used for the project
- `requirements.txt` - Required Python libraries
- `Dockerfile` - Docker configuration file
- `README.md` - Project documentation
- `Screenshots/` - Screenshots of the project

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Joblib
- Jupyter Notebook
- Docker
